# Loop8

برنامج Mac خفيف لمعاينة ملفات Mixamo FBX وتصدير الحركة من ثماني زوايا بفارق 45 درجة.

## المميزات

- تصدير ملف واحد أو فولدر كامل من ملفات FBX بالتتابع.
- خلفية Studio أو Green Screen أو Alpha شفاف.
- دقات مربعة: `512`, `1024`, `2048`.
- جودة فيديو: `Low`, `Medium`, `High`.
- بُعد كاميرا: `Close`, `Fit`, `Wide` للحركات الكبيرة.
- معدلات إطارات: `24`, `30`, `60` FPS.
- اختيار تكرار الحركة من مرة إلى ثلاث مرات.
- فتح ملف FBX جديد من زر `+ FBX` بدون إعادة تشغيل البرنامج.
- المعاينة تعرض الحركة والزاوية الحالية أثناء الريندر.

## التشغيل

```bash
npm install
npm run tauri dev
```

لتشغيل الواجهة فقط داخل المتصفح:

```bash
npm run dev
```

## التصدير

- الصيغة المفضلة من Mixamo: `FBX Binary` مع `Skin` وبدون Keyframe Reduction.
- الحركة الأفقية لعظمة `Hips` تُثبّت تلقائيًا للحصول على حركة في مكانها.
- التطبيق يفضّل MP4/H.264 لخلفيات Studio وGreen Screen.
- الخلفية الشفافة تستخدم WebM VP9 بقناة Alpha حقيقية من خلال FFmpeg.
- لو FFmpeg مش موجود، ثبّته مرة واحدة بـ `brew install ffmpeg` أو استخدم Green Screen.
- الزوايا: `0, 45, 90, 135, 180, 225, 270, 315`.
